**Card anatomy (top to bottom):**

1. **Thumbnail block** — `expo-image` `Image` component, `height: 140`, `contentFit="cover"`, `borderTopLeftRadius: radii.md`, `borderTopRightRadius: radii.md`, `backgroundColor: colors.primary` as placeholder. When `trend.thumbnail_url` is falsy, show a placeholder View with the same dimensions and teal background (no broken image icon).

2. **Platform icon overlay** — positioned `absolute` top-right of thumbnail: `top: 8, right: 8`. Render `<Iconify>` based on platform:
   - `'youtube'` → icon `'logos:youtube-icon'` size 20, color `'#FF0000'`
   - `'x'` → icon `'ri:twitter-x-fill'` size 18, color `colors.text`
   - Unknown/missing → render nothing
   Wrap icon in a small `View` with `backgroundColor: colors.overlay`, `borderRadius: radii.sm`, `padding: 4`.

3. **Content area** — `padding: spacing.md`, `backgroundColor: colors.surface`, `borderBottomLeftRadius: radii.md`, `borderBottomRightRadius: radii.md`.

   a. **Top row** — `flexDirection: 'row'`, `gap: spacing.xs`, `marginBottom: spacing.sm`, `flexWrap: 'wrap'`:
      - Category badge (if `trend.category`): `backgroundColor: colors.primarySoft`, `borderRadius: radii.pill`, px 10 py 3, `labelSmall` text in `colors.primary`
      - Region badge (if `trend.region_code`): `backgroundColor: colors.surfaceMuted`, `borderRadius: radii.pill`, px 10 py 3, `labelSmall` text in `colors.muted`

   b. **Title** — `typography.headingSmall`, `color: colors.text`, `numberOfLines={2}` with ellipsis. `marginBottom: 4`.

   c. **Arabic translation** (if `trend.ar_translation`) — `typography.arabicBody`, `color: colors.textSecondary`, `writingDirection: 'rtl'`, `textAlign: 'right'`, `marginBottom: 4`.

   d. **Footer row** — `flexDirection: 'row'`, `justifyContent: 'space-between'`, `alignItems: 'center'`, `marginTop: spacing.xs`:
      - Metric (if `trend.metric_value != null`): formatted abbreviation + type label. Use manual threshold: ≥1_000_000 → `(n/1_000_000).toFixed(1)M`, ≥1_000 → `(n/1_000).toFixed(0)K`, else `n.toString()`. Append `trend.metric_type` if present (e.g., "1.2M views"). Style: `typography.labelLarge`, `color: colors.accent`.
      - Published date (if `trend.published_date`): display as short locale string (`new Date(trend.published_date).toLocaleDateString()`). Style: `typography.bodySmall`, `color: colors.muted`.

**Outer wrapper:** `Pressable` with `onPress` handler:
```typescript
const handlePress = () => {
  if (onPress) { onPress(trend); return; }
  if (trend.url) Linking.openURL(trend.url);
};
```
Wrap `Pressable` in a `View` with `...shadows.card`, `borderRadius: radii.md`, `overflow: 'hidden'` — shadow requires no overflow hidden on the shadow container (put overflow hidden on inner View, not Pressable).

**Pattern note:** StyleSheet-only (no NativeWind). Import `Linking` from `'expo-linking'`, `Image` from `'expo-image'`, `Iconify` from `'react-native-iconify'`.

**Shimmer animation (Reanimated 3 — NOT v2 API):**
```typescript
import Animated, {
  useSharedValue,
  withRepeat,
  withSequence,
  withTiming,
  useAnimatedStyle,
} from 'react-native-reanimated';

// In component:
const opacity = useSharedValue(0.4);

useEffect(() => {
  opacity.value = withRepeat(
    withSequence(
      withTiming(1, { duration: 700 }),
      withTiming(0.4, { duration: 700 })
    ),
    -1,
    false
  );
}, []);

const animatedStyle = useAnimatedStyle(() => ({ opacity: opacity.value }));
```

All shimmer blocks are `<Animated.View style={[shimmerBlock, animatedStyle]}>` with `backgroundColor: colors.surfaceStrong` (`'#374151'`).

**Outer wrapper:** `View` with `...shadows.card`, `borderRadius: radii.md`, `overflow: 'hidden'`, `backgroundColor: colors.surface`.

**StyleSheet-only**, no inline styles except the animated opacity.
