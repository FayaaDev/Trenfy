
**Query:**
```typescript
const { data, isLoading, isError } = useQuery({
  queryKey: ['trends', filters, cursor, sortBy, sortDir],
  queryFn: ({ signal }) => getTrends({
    ...filters,
    cursor,
    limit: 50,
    sort_by: sortBy ? `${sortBy}:${sortDir}` : undefined,
    signal,
  }),
});
```

**Filter reset helper:** when any filter changes, reset cursor and cursorStack to [] and undefined.

**Pagination:** 
- "Next" button: enabled when `data?.paging.has_more`. On click: push current cursor to cursorStack, set cursor to `data.paging.next_cursor`.
- "Prev" button: enabled when cursorStack.length > 0. On click: pop cursorStack, set cursor to popped value.

**Sort toggle:** clicking a column header (published_date or metric_value) toggles direction if already selected, or sets it as the sort field descending.

**Table columns** (per ADMIN-01):
1. Title — truncate long strings with `className="max-w-[240px] truncate"`
2. Platform — plain text
3. Category — plain text
4. Status — `<Badge>` with variant logic:
   - `'approved'` → `variant="default"` (green-ish primary)
   - `'rejected'` → `variant="destructive"`
   - `'pending'` / null → `variant="secondary"`
5. Region — `region_code` field
6. Published — `format(new Date(trend.published_date), 'MMM d, yyyy')` from date-fns
7. Metric — `trend.metric_value.toLocaleString()`
8. Actions — empty `<TableCell>` placeholder (will be populated in 09-02)

**Filter bar** (above the table, per ADMIN-02):
Use shadcn Select for each filter. Each Select has an "All" option (empty string value = clear filter):
```
Status: All | Pending | Approved | Rejected
Platform: All | YouTube | X
Category: All | gaming | music | entertainment
Region: All | US | SA | JP
```

On filter change: call `setFilters(prev => ({ ...prev, [field]: value || undefined }))` and reset cursor.

**Loading state:** When `isLoading`, render a centered `<div>Loading...</div>` inside the table body (spanning all columns).

**Error state:** When `isError`, render a muted error message row.
