Correct per-element RTL (from rtler skill):
```typescript
arabicText: {
  ...typography.arabicBody,
  color: colors.textSecondary,
  writingDirection: 'rtl',    // ← correct: per-element direction
  textAlign: 'right',         // ← correct: aligns text to right edge
  marginBottom: 4,
}
```

DO NOT use:
- I18nManager.forceRTL() — this flips the entire app layout (wrong for THME-04)
- flexDirection conditionals based on I18nManager — trust the engine
- Any component-level RTL context — only the Text element gets writingDirection
</interfaces>
