  <name>Task 2: Create animated FilterHeader with collapsed badge</name>
  <files>WhiteLabelApp/src/components/FilterHeader.tsx</files>
  <action>
Create `WhiteLabelApp/src/components/FilterHeader.tsx`.

The component should render:
1. Platform row (`ScrollView horizontal showsHorizontalScrollIndicator={false}`)
2. Category row (`ScrollView horizontal showsHorizontalScrollIndicator={false}`)
3. Region row (`ScrollView horizontal showsHorizontalScrollIndicator={false}`)
4. `Clear All` text button only when `activeFilterCount > 0`
5. A collapsed badge anchored to the top-right that says `${activeFilterCount} filter` / `${activeFilterCount} filters`

Animation requirements:
- Export `FILTER_HEADER_HEIGHT = 148`
- Use `useAnimatedStyle` and `interpolate`
- `rowsAnimatedStyle` maps `scrollY.value` from `[0, 80]` to:
  - `translateY: [0, -24]`
  - `opacity: [1, 0]`
  - clamp extrapolation
- `badgeAnimatedStyle` maps `[0, 80]` to:
  - `opacity: [0, activeFilterCount > 0 ? 1 : 0]`
  - `translateY: [8, 0]`

Structure guidance:
```tsx
<View style={styles.root}>
  <Animated.View style={[styles.rows, rowsAnimatedStyle]}>
    <View style={styles.rowHeader}>...</View>
    <ScrollView ...>platform chips</ScrollView>
    <ScrollView ...>category chips</ScrollView>
    <ScrollView ...>region chips</ScrollView>
  </Animated.View>

  {activeFilterCount > 0 ? (
    <Animated.View pointerEvents="none" style={[styles.badgeWrap, badgeAnimatedStyle]}>
      <View style={styles.badge}>
        <Text style={styles.badgeText}>...</Text>
      </View>
    </Animated.View>
  ) : null}
</View>
```

Behavior details:
- Platform chip tap toggles single-select: tapping the active chip sets `null`
- Category chips toggle independently via `selectedCategories.includes(option.value)`
- Region chips toggle single-select: tapping the active chip sets `null`
- If `categories.length === 0`, still render the category row container with a muted `Text` label like `Loading categories...`

Styling details:
- `root`: `height: FILTER_HEADER_HEIGHT`, `justifyContent: 'flex-start'`
- `rows`: `gap: spacing.sm`
- `rowHeader`: `flexDirection: 'row'`, `justifyContent: 'space-between'`, `alignItems: 'center'`, `marginBottom: spacing.xs`
- `sectionLabel`: `typography.labelSmall`, `color: colors.muted`, `textTransform: 'uppercase'`
- `badge`: `backgroundColor: colors.primary`, `borderRadius: radii.pill`, `paddingHorizontal: spacing.sm`, `paddingVertical: 6`
- `badgeText`: `typography.labelSmall`, `color: colors.background`

Do not animate height anywhere in this file.
