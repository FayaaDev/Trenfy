```typescript
const toggleCategory = useCallback((category: string) => {
  setSelectedCategories((prev) =>
    prev.includes(category)
      ? prev.filter((value) => value !== category)
      : [...prev, category]
  );
}, []);

const activeFilterCount =
  (platform ? 1 : 0) + selectedCategories.length + (region ? 1 : 0);

const handleClearAll = useCallback(() => {
  setSelectedCategories([]);
  clearPersistedFilters();
}, [clearPersistedFilters]);
```

Header layout approach:
- Replace the old in-flow header with an absolute overlay at the top of the screen
- Keep title and search row inside a `View` measured with `onLayout`; store the measured height in `headerContentHeight`
- Render `FilterHeader` directly below that measured block using absolute positioning
- Give the list and all fallback states top padding of `headerContentHeight + FILTER_HEADER_HEIGHT + spacing.lg`
- This preserves space for the expanded header while the rows translate out visually with no FlashList re-layout jump

Suggested overlay structure:
```tsx
<View style={styles.container}>
  <View style={[styles.headerOverlay, { paddingTop: insets.top + spacing.sm }]} pointerEvents="box-none">
    <View onLayout={...} style={styles.headerContent}>
      <Text style={styles.headerTitle}>Trending Now</Text>
      <View style={styles.searchRow}>...</View>
    </View>

    <View style={[styles.filterHeaderWrap, { top: headerContentHeight + insets.top + spacing.sm }]}>
      <FilterHeader ... />
    </View>
  </View>

  {/* Loading / error / empty / list all receive paddingTop using header heights */}
</View>
```

FlashList integration:
