  - **ar_translation:** If `trend.ar_translation` is non-null and truthy, show below title: `text-sm text-slate-500 italic`, same line-clamp-2 treatment.
  - **Meta row:** Below translation (or title if no translation):
    - Category: capitalized `trend.category` in `text-sm text-slate-500`
    - Metric: `trend.metric_value.toLocaleString() + " " + trend.metric_type` e.g. "1.2M views", `text-sm text-slate-500`
    - Published: `formatDistanceToNow(new Date(trend.published_date), { addSuffix: true })` from `date-fns` — e.g. "3 days ago"

- Cursor pointer on the whole card (opens source URL on click too, not just the link)

**Accessibility:**
