# Requirements Baseline - v1.2 (Archived)

This archive captures the final outcomes for the v1.2 milestone. The live traceability file was still marked 0/49 complete at milestone close, so the outcomes below were reconciled from phase summaries, verification artifacts, and shipped behavior before archival.

## Carry-Over Still Deferred

- `APP-01..APP-12` remained intentionally out of scope for v1.2 and should be re-scoped in the next milestone.
- `REQ-701..REQ-705` verification debt and the `INFRA-03` human confirmation were not addressed in v1.2.

## Outcome Definitions

- `validated` - shipped as intended and supported by phase summary or verification evidence.
- `adjusted` - shipped with a documented deviation from the requirement wording, but the milestone goal was still met.
- `dropped` - removed from milestone scope.

## Requirement Adjustments

- `DB-02` adjusted: new records default to `pending`, while legacy rows are normalized as pending at read time instead of being backfilled in storage.
- `WEB-02` adjusted: the shipped frontend uses Tailwind v4 because current shadcn tooling no longer supports the older v3 pin cleanly.
