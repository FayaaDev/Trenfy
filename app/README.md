# WhiteLabel Starter

This is a frontend-only Expo starter with local state and mock data so you can reuse it as a white-label base without pulling in backend logic.

## Run

```bash
npm install
npm run ios
```

## What is included

- Onboarding-style welcome screen
- iOS-style bottom tab navigation
- Home, library, activity, and profile screens
- Local mock data and interactive compose/detail sheets
- Centralized design tokens for easy rebranding

## Customize first

- Update app branding in `app.json`
- Replace the placeholder bundle identifiers and package names in `app.json` before shipping
- Replace colors and gradients in `src/theme/tokens.ts`
- Swap sample content in `src/data/mockData.ts`
- Replace icons and splash assets in `assets/`

## No backend required

There are no API calls, auth hooks, storage services, notifications, or server dependencies in this starter.
